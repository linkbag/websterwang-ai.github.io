01 / 出发点

为什么做

研究结果被写进策略简报时，读者往往只看到一个缓解率，很难知道它描述的是哪群患者。Aperture 把队列、结果和来源放在一起，方便分析师在比较项目和撰写简报时随时核查。

02 / 实际用途

项目亮点

  • ↗选中基准表中的一个数字，向助手询问整个剂量组和二线治疗亚组的区别
  • ↗打开已保存的研究结果，核对原文与文献出处
  • ↗在编辑模式下指定四项比较指标，并查看可撤销的修改记录
  • ↗将回答保存为简报，复核措辞，再随 HTML 看板一起分享
